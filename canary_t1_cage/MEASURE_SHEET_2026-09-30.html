T1: what to caliper before the flight prints

Every value below still gates a flight print (ASA / PA12-CF). Grey rows are already measured and are shown only as a reference, so you can check your technique against them. Units are mm unless a row says otherwise. Blue numbers on the drawings match the row numbers.

Now is the value the model uses today. EST = estimated from photos, PUB = datasheet, MEAS = you already measured it. Red in Matters marks rows where being off breaks the fit.
