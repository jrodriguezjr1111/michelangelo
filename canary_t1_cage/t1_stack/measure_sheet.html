T1 stack: measurement sheet

Caliper these before any ladder is printed. Every number in t1_stack/make_t1_stack.scad is an estimate taken from photos 33 to 35, using the cutting-mat grid and the RJ45, USB-A, DP and SMA bodies as rulers. Numbers on the drawings match the rows in the tables. P1 means measure first, because the ladders cannot be printed without it.

All values in mm unless the row says otherwise. Entries are saved in this browser as you type. To send them back, use Copy as CSV and paste the result into the chat.
