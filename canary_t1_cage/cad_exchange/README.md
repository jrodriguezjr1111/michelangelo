Reference solids for the human CAD team (SolidWorks or any B-rep CAD).
Generated by `../make_t1_brep.py` (build123d 0.10 / OCCT), verified by

**These are envelopes, not parts.** Nothing here is a cage design. Section
them, mate to them, keep-out against them.

## Provenance is in the file name

| Prefix | Meaning | Rule |
|---|---|---|
| *(none)* | outline **and hole pattern MEASURED** (repo record); hole diameters nominal unless stated | design against it; confirm hole Ø before cutting |
| `EST_` | **unmeasured placeholder**; class dimensions from a datasheet or the canary memory bank | never cut flight plastic against it |
| `PERCH_` | **a different product** — the Canary Perch ground unit; included only so nobody mistakes it for the T1 compute | not in the T1 |
| `CANON_` | print-validated SlimRig rev-B rod interface, verbatim from `slimrig_mounts` | do not re-dimension |

Frame for every envelope: origin at the centre of the **mounting face**
(board underside / box base), X = long axis, Z = up away from the mount face.
